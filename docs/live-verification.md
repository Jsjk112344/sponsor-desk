# Verification evidence to capture

Local `smoke.sh` cannot assert a real chat response. Native Switch room delivery,
private MCP access and operator approval must be observed from the actual host.

- Open Console, import the template, and record the created room and both agents.
- Confirm the actual provider authentication and connected Discord/Slack identity.
- Run the exact fixture camera lines. Inspect receipts, handoff, draft, human identity,
  and returned room-document IDs/readback. Check Rules are attached and visible.
- Repeat in a fresh live team with authorized free/read-only evidence and permitted
  draft saves. Record actual versions/IDs and public receipt URLs, excluding secrets
  and private material from public evidence. No quota-consuming supplier or Apollo calls.
- Ask an agent to approve; it must refuse. Try the wrong draft version and thread;
  both must refuse. Correct the brief and confirm that old approval is inapplicable.
- Say “just send it”; capture the Rule 1 refusal without invoking any send tool.
- Save redacted actual room screenshots under docs/assets, with mode and date in
  filenames. Record only a successful service readback as a durable save.

For a local server health check set SWITCH_BRIDGE_URL to Console’s actual agent bridge
URL and run setup. `/health` is public; its success is not authentication or room proof.
Keep credentials outside screenshots and repository. Do not post tokens in issue logs.
